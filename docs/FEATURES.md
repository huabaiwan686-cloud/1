# 功能清单（17 页面 · 登录走查实录）

## 内容流

1. **上传资料** `/collector/upload` — 标题/正文（AI 润色、AI 辅助创作）、标签弹窗（约40标签，新标签需审核）、城市级联、客服备注（仅后台可见）、展示资料（免费前10媒体，会员无限+随机推送）、验证资料（拖拽排序）、推送频道多选、定时上架（精确到分钟）、保存草稿/发布
2. **笔记列表** `/admin/notes` — 批量操作 VIP 下拉 10 项（上架/下架/删除/删除编号和标题/查找重复资料/清空频道选择/文本替换/删除后缀/添加后缀/替换最后一行介绍费）、图片搜索（VIP）、多维筛选、五段状态筛选、去重系统（查找重复/分组/清理）
3. **代理采集** `/admin/collection` — 三来源（账号/BOT/好友关注）、规则抽屉（文案前后追加、文本替换、清理标识、介绍费后缀修改、命中删整行、图文去重+时间窗口、屏蔽链接/用户名/纯文本/屏蔽词）、采集后需审核开关；添加采集频道需 VIP
4. **采集审核** `/admin/collection/review` — 批量通过/拒绝/删除，三态筛选
5. **频道配置** `/admin/channels` — 上下架频道分组、频道卡片（编辑/连通性检测/全量推送/清空队列/删除）、推送配置、垃圾消息清理、频道政策页、循环配置、自动删除
6. **群聊推送** `/admin/message-push` + `/publish/message-push` — 风控警示、消息模板（推送/编辑/删除）、推送计划（多账号多模板多时间点）、快速推送
7. **关键字推送** `/admin/group-listen` + `/publish/group-listen` — 监听计划（监听账号/群聊多选/关键词批量添加）、8 位绑定 ID、新手教程弹窗

## 账号体系

8. **TG 账号** `/admin/accounts/protocol` — 扫码/手机号登录（含二级密码）、1U 一号、刷新/重登/删除、账号转移
9. **Bot Token** `/admin/accounts/bots` — 自动创建/手动录入、校验/复制/删除、启用开关
10. **平台绑定** `/admin/accounts/xc-cms-binding` — 绑定码授权资料展示平台
11. **双向机器人** `/admin/accounts/two-way-bots` — TG 账号+Bot 建管理群，群指令 /close /open /ban /unban /info /reset /cleanup
12. **平台合作** `/admin/accounts/platform-cooperation` — 合作申请审核、合作配置、批量导入机器人
13. **好友关注** `/admin/accounts/friends` — 互关统计、@username 申请、五关系标签页、关注配置
14. **账号管理** `/admin/users` — 新增账号、管理员设置（发送后缀、编号/标识插入）

## 变现

15. **VIP 会员** `/admin/vip` — 免费 vs PRO（100USDT/30天，按租户共享）、权益（批次循环上架/无限展示图/防扫图/5000次背景替换/相似查重/图片搜索/代理采集/关键字监听/独立域名）、邀请奖励、账单记录、支付弹窗全流程

## 运营

16. **工作台** `/admin/dashboard` — 8 指标卡、运营趋势图、系统健康
17. **任务记录** `/admin/logs` — 312 页推送日志、动作筛选、失败详情（Telegram 原生错误码）
